# ワイヤーフレーム作成スキル

HTMLで、ワイヤーフレームを作成して。
以下のルールを、すべて守ってください。

【レイアウト】
・読む負担を感じさせない、みてわかるレイアウトにして。
・洗練された、都会的でミニマルなレイアウトにして。
・余白とバランスは、ページ全体をうまく活用して。
・フォントは Noto Sans JP、やや小さめにして。

【デザイン】
・色は「白・黒・グレー」だけにして。
・背景は基本白にして。全面が黒のページは作らないで。
・無駄な英語、線、シャドウなどの装飾は一切しないで。
・図や画像が必要な部分は、グレーボックスにして。
・アイコンは「Font Awesome」の無料版を使って。

【ライティング】
・1文を、やや短くして。読点を1文に最低1度は使って。
・1〜2文ごとに、段落を分けて。
・漢字は違和感がない程度に、ひらがなにして。（例：行う=おこなう）
・強調したい名称やセリフには、記号「」を活用して。
・誤字や脱字は直して、ですます口調に統一して。

## 運用メモ（Claude Code 用）

- 出力は **1枚のHTMLファイル**（インラインCSS）にして、ブラウザで開けばそのまま見られるようにする。
- Font Awesome は CDN（無料版）を `<head>` で読み込む。
- 掲載する原稿・情報を渡された場合は、**テキストは変えないで**、**違和感のない改行**だけ整える。
- **複数ページのサイト**は、チャットのプレビューだと切り替えが難しいので、**ページごとに別のHTMLファイル**に分けて作成・編集する。
- まずは全体の画面構成（セクションの並び）を簡単に示してから、HTMLを出力すると齟齬が出にくい。
