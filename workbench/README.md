# きせかえ競合インテリジェンス・ワークベンチ

決済アプリの「きせかえ × IPコラボ施策」を、**定量カタログ＋定性VOC＋数字メモ**で月次収集するローカルツールです。

- **Python標準ライブラリのみ**（`pip install` 不要）
- データは **このフォルダの `data.json` に実ファイル保存**。バックアップはこのファイルをコピーするだけ
- 通信は **自分のPC内（localhost）だけ**。外部へは一切送信しません（Xを開く時だけ x.com にアクセス）

## 使い方（起動）

### Mac / Linux
`start.command` をダブルクリック。
（初回だけ「実行できない」と出たら、ターミナルで `chmod +x start.command` を一度実行）

### Windows
`start.bat` をダブルクリック。

### 手動で起動する場合
このフォルダで:
```
python3 server.py     # Mac/Linux
py server.py          # Windows
```
起動すると自動でブラウザが開きます（開かなければ `http://127.0.0.1:8765/`）。
**終了するには、ターミナル/コマンドプロンプトのウィンドウで Ctrl+C。**

## 画面

| 画面 | 役割 |
|---|---|
| ① ダッシュボード | 競合・自社ごとの施策検索リンク（公式の施策／生声VOC）と直近の施策・VOC |
| ② 定量カタログ | 主体×IP×キセカエ名×期間の表。Easy Scraper等の**貼り付け取り込み**、月絞り込み、CSV書き出し、数字メモ |
| ③ 検索ビルダー | 表記ゆれ自動。**施策モード**(公式告知)／**生声モード**(VOC)を切替えてXを開く |
| ④ VOC収集 | 生声を賛否タグ付きで蓄積、報告下地に全部コピー |
| ⑤ マスタ管理 | 競合・自社／IPコラボ先／カテゴリ（ジャンル）の登録・編集、JSON書き出し/読み込み |
| ⑥ WF生成 | Claudeに貼れる**ワイヤーフレーム生成プロンプト**を作成（コピペ用） |

## ⑥ WF生成（ワイヤーフレーム生成プロンプト）
Claudeにそのまま貼れる「ワイヤーフレーム生成プロンプト」を組み立ててコピーできます（出典：@hiroho150cm の記事。ルール文は記事のまま）。

- **スキル登録用（初回・推奨）**：出力をClaudeに貼ると、ルールを覚えた**スキル**が登録できます（「保存」ボタンを押すだけ）。次からは「ワイヤーをつくって」だけでOK。※スキルは Pro・Max などの有料プラン向け。
- **このまま単発で作る**：掲載情報を貼り付けてコピー → Claudeに渡すと、その場でHTMLのワイヤーフレームが出ます（「テキストは変えないで」「違和感のない改行にして」のトグルあり）。
- 複数ページのサイトは、デスクトップにフォルダを用意して **Claude Code** でまとめて管理すると編集しやすいです。

## Xから本文を取り込む（ブックマークレット）
「④ VOC」タブの「Xから取り込み（ブックマークレット）」のボタンを**ブックマークバーにドラッグ**して登録します。
Xにログインした状態で**個別の投稿ページ／記事ページ**を開き、そのブックマークを押すと、本文（**記事は全文**）とURLがこのツールに取り込まれ、VOCタブに自動で入ります（賛否タグを選んで保存）。

- 通常の投稿・スレッド・**記事（長文）**に対応。取り込みたい所を**選択（ドラッグで反転）してから押す**と、その部分だけを確実に取り込めます。
- 押すと**新しいタブ**が開きます。ブラウザに**ポップアップの許可**を求められたら許可してください。
- パスワードは一切使いません（ログイン済みの表示をそのまま読みます／外部送信なし）。
- うまく取れない時は本文を手動でコピペしてください。ブックマークバーの表示：Chrome なら `Ctrl/⌘ + Shift + B`。

> 仕組み：ブックマークレットがこのツールのタブを開き、`postMessage` で本文を渡します（URL長の制限を受けないため長文記事の全文も取り込めます）。受信時は送信元が `x.com`／`twitter.com` かを検証します。

## はじめの一歩
1. 「⑤ マスタ管理」で **競合・自社**（名前・公式ハンドル・きせかえ表記）と **IPコラボ先**（IP名・ジャンル）を登録
2. 「③ 検索ビルダー」でXを開いて施策・生声を確認
3. 「② 定量カタログ」に施策を記録（Vポイント等は Easy Scraper で抽出して貼り付け取り込み）
4. 「④ VOC収集」に反応を蓄積 → 月で絞ってCSV/コピーで報告

## バックアップ
- 自動：`data.json` に常時保存
- 手動：⑤の「JSON書き出し」、または `data.json` を直接コピー
